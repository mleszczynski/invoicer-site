Privacy policy

Effective 27 October 2026

Invoicer is a self-hosted invoicing application. It runs entirely on the user's own computer. This policy explains what data Invoicer handles and how.

No hosted service, no data collection

Invoicer has no servers, accounts, analytics or tracking. The developer does not receive, collect or store any data from people using Invoicer. Company details, customers, invoices, receipts and settings are stored only in a local folder on the user's computer.

Google user data

If the user turns on Google Drive backup and connects their Google account, Invoicer requests a single OAuth scope:

  • https://www.googleapis.com/auth/drive.file: create folders and files in the user's Google Drive, and update files that Invoicer itself created.

Invoicer uses this access only to upload copies of the user's own receipts and invoice PDFs to a folder in their Drive, and to replace those copies when the local file changes. It cannot see, read, list or delete any other files in the user's Drive, and it never deletes files in Drive.

The OAuth access token and refresh token are stored only on the user's computer, in the Invoicer data folder. They are sent only to Google, to authenticate requests to the Google Drive API.

Google user data is not transferred to the developer or any third party, not used for advertising, not used to train AI or machine-learning models, and not read by any person.

Invoicer's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other network connections

  • Email: when the user sends an invoice, Invoicer connects to the mail server the user configured (for example Gmail SMTP) and sends the message the user composed.
  • Exchange rates: to convert receipt amounts, Invoicer requests public reference rates from frankfurter.dev, sending only a currency code and a date.

Revoking access and deleting data

Google Drive access can be revoked at any time with Disconnect in Invoicer's Settings, or at myaccount.google.com/permissions. Disconnecting deletes the stored token. Files already copied to Drive belong to the user and can be deleted in Drive. All other data can be deleted by deleting the local Invoicer data folder.
